# 元衡论 V2.0
> 一套融合观照思辨与拓扑数学的思想模型，开源归档仓库

## 项目简介
《元衡论》是持续迭代的思想模型，并非终极真理。
以**势差**为基础结构，正四面体离散耦合拓扑作为数学载体，尝试统一内在觉知认识论与外在现象推演。
内容包含思辨原始记录、体系宣言、数学预印文稿与配套素材，随缘交付，开放阅读、思辨、质疑与校验。
配套预印本：四面体离散面-域耦合扰动系统开放问题 V1，DOI:10.5281/zenodo.1234567

## 阅读建议
1. 优先阅读 `01-综述宣言/元衡论_体系宣言.md`，读懂体系边界与核心立场
2. 可选阅读 `02-推演笔记`，跟随原始思考脉络理解观念生成过程
3. 有余力再查看 `05-数学模型` 的预印本文档与数学推演
4. 配套图片、辅助资料存放于 `06-配套资料`

## 核心声明
1. 本项目仅为思想模型，不等于客观世界实相，不替代科学实验，也不等同修行法门。
2. 无崇拜体系，无强制信条，欢迎独立思辨、批判、校验。
3. 不主动推广，随缘交付，保留持续修订迭代的权利，所有版本变更全部归档可追溯。
